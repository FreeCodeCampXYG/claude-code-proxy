图片工作流

先完善出图提示词，再使用独立图片服务生成结果。

1. 优化提示词

用当前模型把模糊需求整理为可直接出图的描述。

提示词结果会显示在这里。

2. 独立图片生成

确认尺寸与数量后提交；生成期间可随时取消。

图片生成只在同时配置 IMAGE_API_URL、IMAGE_API_KEY、IMAGE_MODEL 时启用。生成结果仅在本页内存中显示，不会写入代理诊断或 Prompt 存档。
生成失败时会保留原始需求与已生成结果，方便调整后重试。下载按钮会保存当前图片。
